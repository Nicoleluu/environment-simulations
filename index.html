Relationships shape the neighborhood.

Iteration two turns the original scene into a connected model. The course specification has not been supplied: all rules below are explicit demo assumptions.

Neighborhoodcontains16 parcelshome parcel hostsBuildinghousesResidents
  • Resident → building: each identified resident lives in exactly one home. Relocation preserves identity.
  • Building → parcel: exactly one building per home parcel. One floor holds 4 residents; two floors hold 8.
  • Parcel → street → gateway: access requires an open frontage and an open graph path to the northwest gateway.
  • Home → park: a home has nearby green space if a reachable park is within 2 street links, excluding the frontage paths at each end. This is a graph measure, not a real walking distance.
  • Building, adding floors, and moving in require street access. Relocation also requires a reachable destination with capacity.
  • Closing a street keeps existing residents in place. Clearing an occupied home is blocked. Park removal immediately changes access scores.

Choose a tool, then click a parcel or use Apply on the selected parcel. Changes save in this browser; Undo and Redo last until reload.
