A neighborhood of possibilities.

This is an illustrative semantic model. No source model was supplied, so these demo rules make the relationships visible and testable.

  • Neighborhood → parcels: 16 fixed parcels, all connected to the street network.
  • Parcel → use: a parcel can contain one home, one park, or remain vacant.
  • Home → residents: each home has capacity for four residents.
  • Build only on vacant, street-connected parcels. Move residents out before clearing a home.
  • Parks are shared green space and do not house residents.

Use the toolbar, then click a parcel. The parcel selector also works with a keyboard. Undo reverses your last edit; Reset restores the example.
